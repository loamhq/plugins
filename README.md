# Archived: each plugin lives in its own repository now

This repository held the first plugins listed in the
[Loam marketplace](https://github.com/loamhq/marketplace), one folder each.
Since 2026-11-18 every Market plugin lives in its maker's own repository,
and Images is built into [Loam](https://github.com/loamhq/loam) itself.

| Plugin | Now |
|---|---|
| Autumn | [michaelhejazi/loam-autumn](https://github.com/michaelhejazi/loam-autumn) |
| Deep Forest | [michaelhejazi/loam-deep-forest](https://github.com/michaelhejazi/loam-deep-forest) |
| Foundry | [michaelhejazi/loam-foundry](https://github.com/michaelhejazi/loam-foundry) |
| Mist Trail | [michaelhejazi/loam-mist-trail](https://github.com/michaelhejazi/loam-mist-trail) |
| Yosemite | [michaelhejazi/loam-yosemite](https://github.com/michaelhejazi/loam-yosemite) |
| Syncthing | [michaelhejazi/loam-syncthing](https://github.com/michaelhejazi/loam-syncthing) |
| Images | built into Loam from 0.2.10 (`plugins/images/`): turn it on in Settings › Plugins |

**The tags stay** (`<id>-v<version>`, e.g. `autumn-v1.0.1`), so every link
to this repository still installs what it did, and a copy installed from one
keeps working. New versions are made in the repositories above.
